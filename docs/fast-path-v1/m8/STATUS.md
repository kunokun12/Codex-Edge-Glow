# M8 source-side status

This branch adds a JVM regression guard that the packaged production authority asset remains empty and cannot authorize a key. The full M8 proposal package, owner decision register, host conformance suite, logs, and source snapshots are delivered in `/root/android-mcp/artifacts/fastpath-v1-m8/`.

The M1 v1 contract remains unchanged. The v1.1 schema and fingerprint/observer contracts are draft-only. Execute, evidence capture, and verification remain unimplemented; production key enrollment, observer pinning, rollback anchor selection, and real-device execution remain blocked pending owner decisions.
